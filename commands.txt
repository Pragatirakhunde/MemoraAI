## Terminal 6 — Install and start Grafana dashboard

Download this monitoring package and place it in your project root.

Download Memora Grafana Monitoring Pack

Then run:

```
cd "C:\Sem5-(TY)\memoraAi\memora_final_project"

Expand-Archive `
  -LiteralPath "$env:USERPROFILE\Downloads\Memora_Grafana_Monitoring_Pack.zip" `
  -DestinationPath "." `
  -Force

docker compose -f monitoring-compose.yml up -d

docker compose -f monitoring-compose.yml ps
```

If the ZIP was saved somewhere other than Downloads, change the ZIP path accordingly.

In Grafana, open Dashboards → Memora → Memora MVP Overview. The dashboard is provisioned automatically and tracks API/frontend availability, API response-probe duration, HTTP status, and TCP reachability for PostgreSQL, Neo4j, Qdrant and Redis.

Change the initial Grafana password after logging in. This is a basic infrastructure/availability dashboard; detailed application metrics such as request counts, AI latency and Celery queue depth require additional instrumentation in the application.
